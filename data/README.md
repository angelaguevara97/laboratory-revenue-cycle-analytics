# Data

All data used by this project is synthetic.

The full generated CSV files are created locally in `data/generated` by running `python src/generate_data.py`. Bulk generated files are intentionally excluded from Git source control because they can be recreated at any time from the generator.

Small sample files can be committed to this directory so recruiters and reviewers can inspect the shape of the data without running the full application.

No protected health information, proprietary laboratory data, or real payer contract data should be added to this repository.
